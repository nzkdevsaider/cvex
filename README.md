# CVeX - Creador de curriculums basado en Latex

## Introducción

CVeX es un creador y organizador de curriculums vitae que utiliza Latex como renderizador de documentos y JSONResume como estructura del currículum. Este es un proyecto educativo que busca encontrar una manera más organizada y sencilla para que las personas puedan crear y estructurar bien una hoja de vida que sea amigable para los sistemas ATS modernos.

**Este proyecto aún no está terminado**. Actualmente la idea principal funciona, pero hay elementos que también me gustaría añadir en el futuro para que se complemente perfectamente. Podrías encontrar errores y siempre puedes reportarlos en la [sección de issues](https://github.com/nzkdevsaider/cvex/issues).

## Motivación

Este proyecto busca atacar varias complicaciones a la hora de crear una hoja de vida y/o curriculum. Una de ellas es simplificar el proceso y estructura del mismo, permitir separar la información de la presentación, estructurar una hoja de vida con elementos destacables e importantes y también facilitar la personalización del mismo sin tener que complicarse por encajar la información nuevamente en un diseño nuevo.
